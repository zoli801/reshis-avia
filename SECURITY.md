# Безопасность

Реальные токены, пароли и серверные ключи в репозитории не хранятся. `.dev.vars.example` содержит только имена переменных с пустыми значениями.

- Локальные значения: `.dev.vars`, файл с правами `600`, исключённый из Git.
- Production: защищённые серверные переменные Sites. Секреты не передаются в браузер.
- Пароли пользователей: случайная соль, PBKDF2 и отдельный серверный `PASSWORD_PEPPER`.
- Сеансы: непрозрачные токены, хеши в базе, защищённые cookie; разграничение прав проверяется сервером.
- Вход ChatGPT в production требует доверенного шлюза Sites. Локальная эмуляция предназначена только для разработки на loopback-адресе.

Перед коммитом и отправкой изменений запускайте проверку секретов. Локальные Git hooks подключаются командой `git config core.hooksPath .githooks`. Не добавляйте реальные секреты в примеры, тесты, скриншоты, Issues или журналы CI.

```sh
git config core.hooksPath .githooks
node scripts/check-secrets.mjs --mode working
node scripts/check-secrets.mjs --mode staged
node scripts/check-secrets.mjs --mode history --ref HEAD
```

Проверка индекса читает содержимое будущего коммита, а проверка истории — также удалённые из текущей версии файлы. Hook перед push проверяет каждую отправляемую ветку. Дополнительный параметр `--known-env /путь/к/локальному/файлу` сравнивает значения секретов и их URL/Base64-представления, не печатая их. Отчёты `--manifest` и `--verify-manifest` связывают проверенный набор файлов с их SHA-256 и сохраняются только вне репозитория.

GitHub Actions проверяет историю встроенным сканером и Gitleaks **8.30.1**. Бинарный файл Gitleaks загружается из официального релиза и проверяется по закреплённому SHA-256. Единственное дополнительное исключение — точное значение официального **публичного** ключа Telegram в `lib/server/auth.ts`; настоящие токены этим исключением не покрываются.

Для сообщения об уязвимости используйте приватный раздел GitHub **Security → Advisories → Report a vulnerability**, если он доступен. Не публикуйте действующие ключи и персональные данные в открытом Issue.
